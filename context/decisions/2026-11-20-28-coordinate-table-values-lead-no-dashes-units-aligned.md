# 2026-11-20 - Coordinate table: values lead, no dashes, units aligned, rows tighter

- **Nov 20 2026: the Location details coordinate table is improved.** The designer, with a screenshot of the Location information card: "Improve this design, please", through `/emil-design-foundations`. One shared component, `_shared/location-details-table.tsx`, so every record type (project records, Explore's record page, observations) gets it.
  - **Findings and changes.** (1) Hierarchy was inverted: the coordinate names were black and medium, the numbers grey. The names are now quiet (tertiary) and the values primary, tabular figures kept. (2) Three dashes sat in the Entered Value column and a dash in every cell where there were no coordinates: a stray `-` (2.3, 2.12). Those cells are empty, with "Not entered" for a screen reader. (3) "m" was glued to Easting and Northing only, so the decimal points zig-zagged; every value now has a unit slot of one width after it (quiet, xs), so the decimals stack in both columns. (4) Rows were 45px, so the table ran 261px and set the map's height beside it; rows are 36px and the table 221px, with the map matching.
  - **Not changed.** The header labels ("Entered Value", "GDA2020 Equivalent") are the frame's wording and keep their capitals; sentence case would be a copy decision against the Figma. The table's values and derivation (`toMga2020`) are untouched.
  - **Verified live** (registered user, Kangaroo Island, Flinders Chase Recovery Site; Explore's record page): names grey and values dark; Zone, Easting, Northing show empty entered cells; decimals aligned (655,144.16 and 6,021,339.36 end together, the latitudes and longitudes too); the table is 221px at 1716 wide with the map beside it at 269px; zero console errors. `tsc` and `check:contracts` clean. Not checked: a record with no coordinates (every cell empty), touch.
  - **Open.** Whether the capitalised header labels should become sentence case; whether the empty "Entered Value" column is worth its width when only latitude and longitude are ever entered (it is the frame's, so it stays).
