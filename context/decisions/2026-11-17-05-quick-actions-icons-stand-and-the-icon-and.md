# 2026-11-17 - Quick actions icons stand and the icon and arrow pair is for Quick actions only

- **Nov 17 2026: The designer answered the two open questions of `2026-11-17-04`.** (1) "Yes": the three icons stand (`Folder` on Manage projects and datasets, `FileLock01` on Data licence request, `Feather` on Sensitive species nomination). (2) "Only quick actions": the leading icon plus trailing arrow is not applied to other buttons that move on.
  - **Decided.** Both answers are the designer's, so the icon choices in `04` are no longer an agent call. 3.12 stays as written for every other button; the override in `04` still covers only these three buttons and is not a precedent (0.1).
  - **Why Quick actions differs from "Continue ->" (the designer's question).** It does not differ in the arrow: "Continue", "View request" and the like are `link-color` buttons whose one icon is the trailing `ArrowNarrowRight` (`home-dashboard.tsx`, `TaskItem` and `ContinueStrip`), the same arrow the Quick actions carry. The difference is only that Quick actions are outlined `secondary` buttons that also carry a leading icon naming the kind of thing. A link-style button is outside 3.12 ("Not action buttons"), so the pair is the one thing here that 3.12 does not allow.
  - **Open, for the designer.** Whether 3.12's table should gain an entry for each of the three icons, so the set stays the one place every action's icon is named. "Yes" to the question in `04` could be read as that or as "the icons stand"; it was taken as the second, and the table is not edited (9.4). It is also still open whether 3.12 should allow the pair for outlined buttons in general (the designer said not).
  - **Touches:** `2026-11-17-04`, contracts 3.12.
