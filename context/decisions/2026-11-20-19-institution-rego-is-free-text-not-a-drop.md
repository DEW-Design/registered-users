# 2026-11-20 - Institution rego # is free text, not a drop-down

- **Nov 20 2026: Institution rego # is a free-text field.** The designer: "institution rego # is a free-text field not a drop-down, please fix." It was drawn as a select with five registers (Mammals, Birds, Herpetology, Invertebrates, Vascular plants).
  - **Changed.** In `occurrenceSections` (`survey-data.ts`) the row is a text field on both the Individual's Voucher section and the Population's one-field Voucher section; its option list is gone from `field-options.ts` (`SELECT_OPTIONS`); and the "Pre-fill sample content" no longer fills it with "Mammals" (`record-sample.ts`: a registration number has no honest sample, so it stays empty, 0.3 and 3.14).
  - **Supersedes part of `2026-11-20-10`.** Explore's seeded records no longer carry a rego derived from the species group (a register name is not a registration number, and a number made up to look real is an invented identifier). The Institution rego # column in Explore's table therefore shows a value only where the record holds one: the one hand-written voucher (the Southern Brown Bandicoot, whose value in the sample data is still the old register word "Mammals", left as it was written). The Records report's rego column and the specimen reports' derived register (`REGO_FOR_GROUP`, labelled a sample there) are unchanged.
  - **Verified live** (BioData Admin, Adelaide Hills, the bandicoot's record): the Voucher tab reads "Institution rego # Mammals" and in edit mode the field is a text input holding it; zero console errors. `tsc`, `eslint` and `check:contracts` clean.
  - **Open.** Whether the sample data's "Mammals" should become a number-like text, and whether Explore's rego column should carry sample registration numbers at all, are for the designer.
