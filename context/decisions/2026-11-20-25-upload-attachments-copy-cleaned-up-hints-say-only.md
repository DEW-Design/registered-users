# 2026-11-20 - Upload attachments copy cleaned up: hints say only a default

- **Nov 20 2026: the microcopy of the Upload attachments modal reads plainly.** The designer, with a screenshot of the optional details: "Please clean up the UI copy, thanks. It reads a bit weird."
  - **The fault.** Under the details fields, hints were a mix: some restated the label ("What it shows or records." under Description, "The date it was made." under Created, "Who made it." under Creator), some said a default in three different shapes ("The file name is used if empty.", "CC-BY if empty.", "Adelaide Hills Landcare if empty."). A field does not carry a sentence that says what it is (2.12), and a fact is said once, the same way (2.18).
  - **Now.** The hints say only a default, leading with it: "Defaults to the file name.", "Defaults to today.", "Defaults to you.", "Defaults to CC-BY.", "Defaults to Adelaide Hills Landcare." (the project's publisher), "Defaults to the publisher." Description has no hint. The panel heading is "Optional details" (it was "Details (optional)"). The concept control is labelled "Concept" (the product's and the template's word), where "Attach to" after "Record" read as a second verb; a record's own Add attachment, which shares it, reads the same. The modal's lines: "Add one file, or many files and links with this project's template."; the drop area says "One file, a ZIP of the template and its files, or the template alone for links"; the error says "Add a file, or a ZIP with your filled-in template and its files." The defaults named are the ones the viewer really uses (file name, who adds it, today, CC-BY, the project's publisher, the publisher).
  - **Method.** `/refine-prompt` with the design vocabulary (microcopy, placeholder, front-loading, sentence case); the engineering pass had nothing to translate.
  - **Verified live** (registered user, Upload attachments with a PDF and the details open, 2x screenshot): labels Record, Concept, Title, Description, Created, Creator, Licence, Publisher, Rights holder; every hint as above; zero console errors. `tsc`, `eslint`, `check:contracts` clean. Not committed.
  - **Open.** "Defaults to you." names the person adding the file; whether the form should show their name instead is for the designer. The template sheet's own hint text ("Optional. Who made it.") was not changed (out of scope).
