# 2026-11-20 - Explore's table toolbar is search, Filter, Columns and an Export button

- **Nov 20 2026: Explore's Map and table toolbar follows the report pattern, search then Filter at the left, Columns then Export at the right; the "..." menu is gone.** The designer, with a screenshot: "violates patterns - search, filter. columns. ditch the three dot menu and have export as chevron down button instead."
  - **Search.** The table had no search box of its own, because the search card's field is Explore's one search (4.6, "two different search bars"). `DataReport` gets an opt-in `onSearchChange`: with `search` it draws the toolbar search box, writing to the screen's one keyword, so the card's field and the table's box always read the same (typing "Emu" in the table's box leaves 5 rows and the card's field reads "Emu"). The two boxes are visible together in the split view, which the designer asked for here; the alternative, kept for the designer, is to leave the table without a box and say so.
  - **Export.** `ReportExportButton` (`reports/report-export-button.tsx`) is one secondary "Export" button, a download icon before and a chevron after, opening Export CSV and Export XLSX (the report's own actions for the rows in view), as a template's Download does (`template-downloads.tsx`). `DataReport` takes it through `exportButton` (with `header="none"`, as Explore uses it); every other report keeps its "..." menu. A guest still has to sign up: the same button asks for it (`onBlocked`) with its tooltip, in place of the old "Export data" link.
  - **Verified live** (registered user and public user): toolbar order search, Filter, Columns, Export, full screen; the Export menu lists Export CSV and Export XLSX and the CSV downloads as `explore-species-records.csv`; the guest's button opens the sign-up prompt; no "More actions" button; zero console errors. `tsc`, `eslint` on the touched files and `check:contracts` clean. Not checked: touch emulation, and the XLSX download itself. Not committed.
  - **Open.** The report pattern's other records pages keep the "..." menu for their exports (4.6); whether they should take the Export button too is for the designer. The search box's text is "Search by species, NSX code, project or sighting", the report's own; the card's says "Search a species or keyword".
