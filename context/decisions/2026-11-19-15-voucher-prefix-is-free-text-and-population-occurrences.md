# 2026-11-19 - Voucher prefix is free text and Population occurrences have a Voucher section

- **Nov 19 2026: Voucher prefix is free text and Population occurrences have a Voucher section, per direct request (branch `mohan-wips`).** Source: the designer's Figma screenshot of Voucher number, "[Voucher Prefix] Voucher Number": "The voucher ID prefix must be a free text and the voucher number is a number field as it is. The Voucher details section must be available for the population occurrence as well."
  - **Prefix.** It was a grey box worked out from the Institution name (`INSTITUTION_PREFIX`: South Australian Museum is SAM, State Herbarium is AD). It is now a free-text `Input` beside the number's `InputNumber` (`VoucherControl`, `field-controls.tsx`), set by the person and not by the institution. `INSTITUTION_PREFIX` is removed.
  - **Storage.** One row, "Voucher number", still holds one string, "<prefix> <number>" ("SAM 24518"), read and written by `parseVoucher` and `formatVoucher` (`field-schema.ts`). The data model, the field visibility and the notes keep one voucher number field, so nothing else moved. The records report's Voucher series and Voucher number columns now read the same two parts, not the institution. Seed `voucher` data gains `prefix`. Known edge: a prefix with no number that is all digits reads back as a number.
  - **Hint.** Shown only once a prefix is typed, as in Figma: `Shown as "AD number"`, then `Shown as "AD 24518"`. The line "The prefix comes from the institution" is gone because it is no longer true.
  - **Population.** `occurrenceSections` no longer limits the Voucher section to Individual: every occurrence has it, folded under an event like the other optional sections (`occurrenceStart`). The Add occurrence lab's option descriptions are updated.
  - **Sample content.** The voucher sample is "SAM 1".
  - Verified in a browser as the BioData Super Admin: Population occurrence OC00501 shows a Voucher card in edit, prefix "AD" and number 24518 give the hint "AD 24518" and save as "AD 24518"; Individual OC00504 still reads "SAM 24518". `tsc`, `eslint` on the touched files and `npm run check:contracts` pass. Not measured: touch targets, other roles, typography against computed styles (the prefix is the design system's `Input`, so its type is the component's). Not committed.
  - **Open, for the designer (0.4).** Whether the prefix should be capped in length or forced to capitals; whether the Voucher section should be open, not folded, on a new Population occurrence.
