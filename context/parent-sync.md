# Changes to carry back to the parent

Every change made in this repo (the user testing edition) that the prototype repo (`sai-wips`, DEW-Design/Biodata) should also get, or should decide on. One row per change, newest first. The decision file holds the why; this table is the checklist.

- A row is added in the same pass as the change and its decision entry (`npm run decision:new`).
- **Ported** is the one column that is edited afterwards: `no` until the change is in the parent, then `yes` with the parent commit.
- Rows are not deleted. A change that is dropped is marked `dropped` with the reason.
- **Edition only** marks a change that belongs to this repo alone (one role, no tools bar) and should not go to the parent. It is still listed, so nobody has to ask.

Base: this repo was cut from `sai-wips` at `eac2785` (17 Nov 2026). `mohan-wips` 1c286ee (a commit on top of eac2785) was merged in on 25 Nov 2026.
